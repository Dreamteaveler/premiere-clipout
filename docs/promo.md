# ClipOut 1.1.10 面板截图

支持 Premiere Pro 2021–2026。需要 Windows x64，以及与 Premiere Pro 相同主版本的 Adobe Media Encoder；补丁号无需一致。

![ClipOut 1.1.10 实际面板](images/clipout-1.1.10-panel.png)

此图为当前正式安装的 1.1.10 真实面板截图，仅裁取插件区域，没有重绘界面。截图不含工程素材、个人路径或日志。面板固定读取本机 H.264／WAV 格式，并显示“被禁用的片段不会被导出”提示。

只加入 AME 队列，不自动启动编码。双边或未分类转场及已识别的跨轨遮罩依赖当前跳过；其余功能说明见 [README](../README.md)。
